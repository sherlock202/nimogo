## NimoGo v1.4.5

阅读和讲稿里的繁体字会整段换成简体再显示。

**修复：讲稿里的繁体字仍显示不出来**
- 上一版只换了特别生僻的字。「惡」「從」「裡」「擊」这类常见繁体其实也不在眼镜字库里，这次和通知一样整段换成简体。
- 例如：「義人和惡人都從你那裡」显示成「义人和恶人都从你那里」。
- 图片阅读和提词器讲稿都生效。开关还是「文字显示：缺的字换个写法」，默认开着。

**v1.4.4 的内容**
- 阅读和讲稿开始把字库里没有的繁体换成简体。这一版把没换到的常见繁体也补上了。

**使用前**
- 从旧版本直接覆盖安装即可，设置不会丢。安装包只支持 64 位手机。

**已知限制**
- 日语离线模型的输出没有标点，日语里夹的英文词会写成片假名；对方离得远、声音小时，准确度仍不如在线 Whisper。
- 「外语用在线」时，在线前的确认要用 SenseVoice，所以两个离线模型都要下载。
- 个人测试版本，只在 Android 16 上实测过。非官方项目，与 Nimo 厂商、Google、Meta 都没有关系。
