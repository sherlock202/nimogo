## NimoGo v1.4.8

系统自带的看板（官方主界面）上，右镜腿双击也会打开语音菜单。

**语音菜单**
- 眼镜自己的系统看板开着时，右双击打开语音菜单。有的眼镜只报两次单击、不报双击，0.4 秒内再按一次也算。
- 右单击仍是原来的：NimoGo 看板开着用时，点一下叫回 NimoGo 的看板。
- 从这个界面打开的菜单，右单击或右镜腿长按关掉后回到系统看板。说「看板」才打开 NimoGo 的看板。
- NimoGo 自己的看板正显示着时，右双击照旧打开语音菜单。

**v1.4.7 的内容**
- 看板上右双击打开语音菜单，念出功能名就启动。v1.4.6 编译没通过，没有安装包。

**使用前**
- 从旧版本直接覆盖安装即可，设置不会丢。安装包只支持 64 位手机。

**已知限制**
- 日语离线模型的输出没有标点，日语里夹的英文词会写成片假名；对方离得远、声音小时，准确度仍不如在线 Whisper。
- 「外语用在线」时，在线前的确认要用 SenseVoice，所以两个离线模型都要下载。
- 个人测试版本，只在 Android 16 上实测过。非官方项目，与 Nimo 厂商、Google、Meta 都没有关系。
