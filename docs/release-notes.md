## NimoGo v1.4.0

场景助手听得懂日语了：日语、英语场景改用在线 Whisper 转文字，翻译也可以交给大模型；AI 代理的消息在眼镜上一直显示，按右镜腿才关。

**改进：场景助手的日语、英语**
- 转文字分三档：手机离线 / 外语用在线（默认）/ 全部在线。场景语言是日语、英语、自动时用在线的 Whisper（推荐 Groq 的 whisper-large-v3，有免费额度），
  远处对方说的日语也认得准；中文场景照样手机离线。没网、额度用完时这一句自动改用离线。
- 场景助手有自己的在线转文字设置；大模型用 Groq 时不用另外填 Key。
- 不再把噪音当成话：在线转文字前先用手机离线确认是人在说话（确认过后 3 秒内的句子直接转），
  Whisper 对着噪音编的「ご視聴ありがとうございました」「谢谢观看」之类会被丢掉，连续重复的同一句也只留一次。
- 「离线时自动识别语言」只用在中文场景，日语场景不再被当成中文。

**新增：即时翻译可以用大模型**
- 「场景助手 › 设置 › 即时翻译 › 用什么翻」选「大模型」：比离线翻译通顺得多、专业名词更准（每句约 1 秒，要联网）；出错时这句自动改用离线。

**改进：AI 代理**
- 代理的消息在眼镜上一直显示，按右镜腿才关（还有下一条就接着显示），双击翻页；要你确认的消息左单击直接回复。
  导航等功能开着时先弹一下，关掉后再一直显示。不想一直显示可以在「AI 代理」页关掉。
- 代理每次写 GitHub 都要审批时（比如 Muse），可以让它改发手机通知「NimoGo #编号：……」：NimoGo 替它写回 GitHub、显示到眼镜上，
  你的回复也追加到 Issue 正文，代理只读就能看到。「最近收到的通知」里可以排查通知来自哪个 app。

**使用前**
- 外语场景用在线转文字时，每句录音会发给你设的在线服务（比如 Groq）；不想发出去就在「转文字」里选「手机离线」。
- 收代理的通知要给 NimoGo「通知使用权」。
- 从旧版本直接覆盖安装即可，设置不会丢。安装包只支持 64 位手机。

**已知限制**
- 对话进行中旁边突然有人大声说话，仍可能被转成一句；远处的人在说话时也会被当成对方。
- Groq 免费额度有每分钟次数上限，转文字、翻译、要建议共用一个 Key，对话很密时可能退回离线。
- 个人测试版本，只在 Android 16 上实测过。非官方项目，与 Nimo 厂商、Google、Meta 都没有关系。
