## NimoGo v1.2.1

场景助手：面试、商务谈判、相亲约会的随身军师。轻按镜腿，眼镜上就有参考回答和该问的问题——关键场合就像开了挂。

**新增**
- 「商务谈判」场景：对方压价、拖延、拿竞争对手比较时给你应对的说法，帮你摸清对方的预算、底线和拍板的人；
  复盘整理谈成了什么、哪些口头承诺要书面确认、下次怎么谈。老用户更新后场景列表里会自动出现。
- 「相亲」改名「相亲约会」，说明也改成适合约会。
- 普通版带「面试」场景；点「更多场景」或「添加」时，app 里会说明怎么购买私人定制密钥，联系方式和设备码可以一键复制。

**场景助手能做什么**（v1.2.0 起）
- 眼镜一直听，手机上转成文字，分出「我」和「对方」，我说的标【我】。
- 右镜腿（戒指下键）：3 条参考回答，针对对方最近说的话；左镜腿（戒指上键）：3 个提问建议；同一个键再按收起。
  没听清对方的话时，复述确认一句再按，会以你的复述为准。
- 中文里夹英文专业名词：场景里写上专业名词，或改用在线转文字（Groq Whisper）。
- 手机黑屏放口袋，戒指、耳机键、音量键翻页；不弹通知，长按镜腿不退出。
- 结束后复盘：面试看职位是否适合你，谈判看条件和风险，约会看对方的性格和值得再确认的地方。

**使用前**
- 场景助手要先下载离线转文字模型（约 166 MB），或者在设置里改用在线转文字；大模型用你自己的 Key（Groq、Gemini 有免费额度）。
- 导航要用你自己的 Google Maps Platform API Key；先强行停止 Nimo 官方 app，再用 NimoGo 连接眼镜。
- 从旧版本直接覆盖安装即可，设置不会丢。安装包只支持 64 位手机。

**已知限制**
- 分辨「我 / 对方」靠音量：开头几句可能显示「分不清」；点手机上的那句话可以改，改过之后分得更准。
- 只凭文字判断不了一个人是否说谎，复盘只会指出「值得再确认」的地方。对方并不知道你在转写，请遵守当地法律、尊重对方；有的面试禁止使用辅助工具，请自己判断。
- 个人测试版本，只在 Android 16 上实测过。非官方项目，与 Nimo 厂商、Google 都没有关系。
