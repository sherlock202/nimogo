## NimoGo v1.1.1

语音跟读的改进：跟读时镜腿翻页不再被拉回、开头更容易跟上、认日文假名；提词器文字里显示不出来的日文汉字换个写法。

**语音跟读**
- 讲稿开头是很短的标题（例如两个字）也能马上跟上。
- 修正：跟读时用镜腿翻页，位置马上又被拉回原来念的地方，看起来像镜腿没反应。现在用镜腿、戒指、音量键、手机上的翻页按钮翻页或跳章节，
  都会从眼镜上这一屏重新找，翻页前念的话不会再把位置拉回去。
- 认日文假名：讲稿里的「ナスカ」和识别出的「なすか」「ナスカ」能对上，识别成中文音译时也能对上一部分。
  日文汉字仍按中文读音对齐：用日语念、识别结果是汉字时对得上，是假名时对不上，可以用戒指翻过去。

**提词器文字**
- 「欅」这类日文新字体在提词器文字里显示不出来（繁体字大多能显示）。文字显示（包括跟读时）会把眼镜字库里没有的字换个写法：
  先换成繁体（欅→櫸、駅→驛、気→氣），没有繁体再换成简体，共 622 个；繁体字照常显示，不会被换成简体。
  「阅读显示 › 文字显示：缺的字换个写法」可以关掉。

**其他修正**
- 提词器文字显示时长按右镜腿，眼镜一直显示「正在退出」：现在会正常退出（同时停止自动滚动和语音跟读）。

**使用前**
- 导航要用你自己的 Google Maps Platform API Key（设置步骤见 README）。
- 先强行停止 Nimo 官方 app，再用 NimoGo 连接眼镜。
- 从旧版本直接覆盖安装即可，设置不会丢。安装包只支持 64 位手机。

**已知限制**
- 语音跟读：讲稿里的人名、片假名外来语常常识别不准，跟不上时用戒指翻；识别和眼镜刷新加起来，大约在念完 0.5～1 秒后跟上。
- 字库替换是按 GB2312 + Big5 估计的：个别日文汉字可能还是显示不出来。
- 个人测试版本，只在 Android 16 上实测过。非官方项目，与 Nimo 厂商、Google 都没有关系。
