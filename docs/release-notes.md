## NimoGo v1.1.2

看板跟着眼镜的「抬头显示」设置；通知停留更久、按镜腿就能关、提词时不打扰；语音跟读位置更准、跟得更快。

**看板**
- 跟着眼镜自己的「抬头显示」设置（和官方 app 里的是同一个），NimoGo 不再单独设置、默认也不再抬头就显示。
  - 开着：和以前一样，抬头显示看板，低头收起。
  - 关着：显示时右单击收起、回到官方主界面，左单击翻屏；在主界面上点一下镜腿叫回看板。
- 「看板设置」里的抬头开关直接开关眼镜的「抬头显示」。
- 修正：眼镜把刚打开的看板页面退掉时，手机上还显示「看板显示中」、眼镜上却是主界面。现在会再打开一次，还不行就把手机上也改成已收起。

**通知**
- 看板和图片显示的阅读上，通知由 NimoGo 画出来，默认停留 10 秒（「通知转发」页可选 5 / 10 / 20 / 30 秒）；显示着时右单击立即关掉。
- 提词时不打扰（默认开）：眼镜上在显示阅读、提词时，手机通知、来电提醒、景点介绍都不弹，只记在日志里。

**语音跟读**
- 修正：阅读设成图片显示时，跟读用的还是图片的排版（7 行），提词器只显示 5 行，正在念的行跑到最下面，选「倒数第二行」时干脆看不到。
  现在跟读开始时按提词器文字的行数、字数重新排版，结束后换回来，位置不变。
- 识别改成 3 秒窗口、每 0.3 秒一次，跟得更快。
- 「正在念的行」只留「中间」「倒数第二行」两个选项。

**使用前**
- 导航要用你自己的 Google Maps Platform API Key（设置步骤见 README）。
- 先强行停止 Nimo 官方 app，再用 NimoGo 连接眼镜（「抬头显示」关着时，点镜腿叫回看板要靠眼镜发给手机的报告，官方 app 连着时 NimoGo 收不到）。
- 从旧版本直接覆盖安装即可，设置不会丢。安装包只支持 64 位手机。

**已知限制**
- 「抬头显示」关着时，看板收起后看到的是官方主界面，叫回时也会先露一下主界面：眼镜关屏时只上报长按右镜腿，而长按是眼镜自己的退出，退出后不接受马上重开页面，所以这时不能用关屏收起。刚收起的 3 秒内点镜腿不会叫回。
- 提词器文字和官方主界面上的通知用眼镜自带的弹窗，停多久由眼镜决定，也关不掉。
- 语音跟读：讲稿里的人名、片假名外来语常常识别不准，跟不上时用戒指翻；识别和眼镜刷新加起来，大约在念完 0.5～1 秒后跟上。
- 个人测试版本，只在 Android 16 上实测过。非官方项目，与 Nimo 厂商、Google 都没有关系。
