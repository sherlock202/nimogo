## NimoGo v1.0.2

导航好用了一些：剩余距离和到达时间改对了，眼镜上加了小地图，到了终点会自动结束。

**改动**
- 修正剩余距离和预计到达时间：以前会显示成几万公里、几千小时。
- 眼镜左边加了小地图：路线形状、当前位置、下一个转弯点，前进方向朝上，比例尺随转弯距离自动调整。「导航 › 设置」里可以关掉。
- 小地图上，要转弯、过马路、走岔路的路口用淡的细线画出来。形状是按转向估的，不是真实路网（T 字路口也会画成十字）。
- 走路方向：刚拐过路口就能认到新的那条路；走错方向时，位置三角会歪过去。
- 手机放在胸前口袋时用指南针，站着转身三角也会跟着转。开始导航后正常走几秒，会自动对准手机的朝向；手机平放或换了放法会自动改用 / 重新对准。
- 到了终点会自动结束导航（以前有时一直停在最后一步）。

**使用前**
- 导航要用你自己的 Google Maps Platform API Key（启用 Navigation SDK，要绑结算账号；每月前 1000 个目的地免费）。设置步骤见 README。
- 先强行停止 Nimo 官方 app，再用 NimoGo 连接眼镜。
- 从 v1.0.0 / v1.0.1 直接覆盖安装即可，设置不会丢。

**已知限制**
- 位置会吸附到道路上，地图上显示在马路中间；不会提示走马路的哪一侧（Google 导航没有这类信息）。
- 指南针只在手机竖着放（胸前口袋）时用；还没对准时，只有走动时三角才会转。
- 个人测试版本，只在 Android 16 上实测过导航。
- 非官方项目，与 Nimo 厂商、Google 都没有关系。
