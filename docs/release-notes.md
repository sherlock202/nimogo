## NimoGo v1.4.2

手机通知里的繁体字会先转成简体，再显示到眼镜上。

**修复：通知里的繁体字显示不出来**
- 收到的手机消息，标题和正文里的繁体字换成简体后再弹到眼镜上。眼镜的通知字库缺一部分繁体，原来这些字显示不出来。
- 简体、英文和标点保持原样。阅读和提词不变。

**v1.4.1 的内容**
- 场景助手加了日语专用的离线模型 ReazonSpeech（约 160 MB）。下好后，日语场景走手机离线时自动用它；中文场景仍用 SenseVoice。

**使用前**
- 从旧版本直接覆盖安装即可，设置不会丢。安装包只支持 64 位手机。

**已知限制**
- 日语离线模型的输出没有标点，日语里夹的英文词会写成片假名；对方离得远、声音小时，准确度仍不如在线 Whisper。
- 「外语用在线」时，在线前的确认要用 SenseVoice，所以两个离线模型都要下载。
- 个人测试版本，只在 Android 16 上实测过。非官方项目，与 Nimo 厂商、Google、Meta 都没有关系。
