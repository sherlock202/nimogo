## NimoGo v1.5.0

新功能：**锻炼**。在手机上建运动组，眼镜上显示动作、完成次数和进度环。

**运动组**
- 「功能 → 锻炼」里新建运动组，名字自己起（比如室内健身）。可以建多个。
- 一组里加多个动作。每个动作设次数和每次多久，单位选秒或分钟。
  - 深蹲：10 次、每次 2 秒
  - 慢跑：1 次、30 分钟
- 动作之间可以设休息（0 为不休息）。一组可以循环多次。最后一周之后不休息。
- 动作可以上下调整顺序、编辑、删除。

**眼镜上的锻炼**
- 选中一组点「开始」，眼镜上显示动作名字、已完成次数（例如 已完成 3 / 10）、剩余时间。
- 进度环和番茄钟一样，按每次的时长转一圈：深蹲每次 2 秒，环就 2 秒转一圈。
- 休息时显示「休息」和下一个动作。做完一组会在眼镜上提醒。
- 右单击开始 / 暂停，左单击算这次做完，右双击跳过这一项。
- 语音菜单里也有「锻炼」，说「锻炼」或「健身」就直接开始选中的那一组。

**说明**
- 离开锻炼页、锁屏也照常计时。手机被杀或重启后，会接着上次的进度；中间过去的时间里，做完的次数会算进去。
- 另一组还在进行时，再开始别的组会先问一声，确认后从头开始新的一组。

**其他**
- 上一版（1.4.11）的内容也都包括在内：系统看板上左单击开语音菜单，连点三次开 AI 代理；语音菜单排成多列；长按右镜腿退出后清掉「正在退出」。

**系统看板上的左镜腿**
- 单击：语音菜单。
- 双击：场景助手。
- 0.4 秒内连点三次：AI 代理。

**语音菜单**
- 排成多列，一打开就全部看见。选中的一条用【】括起来。
- 蓝牙戒指：上键、下键换行，左键、右键换列，中间键启动。手机息屏时，音量加 / 减是上下，播放键是确认。
- NimoGo 的看板正显示着时，右双击打开。念出名字就马上启动。

**说明**
- 系统看板上右镜腿、左长按眼镜都不上报，这是眼镜固件的限制，App 收不到。

**使用前**
- 从旧版本直接覆盖安装即可，设置不会丢。安装包只支持 64 位手机。

**已知限制**
- 日语离线模型的输出没有标点，日语里夹的英文词会写成片假名；对方离得远、声音小时，准确度仍不如在线 Whisper。
- 「外语用在线」时，在线前的确认要用 SenseVoice，所以两个离线模型都要下载。
- 个人测试版本，只在 Android 16 上实测过。非官方项目，与 Nimo 厂商、Google、Meta 都没有关系。
