## NimoGo v1.3.0

场景助手能翻译了：对方说日语、英语时，眼镜上原文下面直接出中文。另外加了「AI 代理」，提词器也修了一批问题。

**新增：即时翻译（场景助手）**
- 对方说日语或英语时，眼镜上原文下面一行「→ 中文译文」；你说的话不翻，对方说中文时也不翻。
- 每个场景单独开关：场景助手页上的「即时翻译」，进行中也能随时开关；也可以在「编辑场景」里设。
- 翻译在手机上离线做（Google ML Kit），一句几十毫秒，对话不发出去。第一次打开时下载离线语言包（中文、日语、英语，每种约 30 MB）。
- 原文和译文都记在这一场的记录里；以前的记录可以「翻成中文」补翻，「复制对话」带上译文。
- 翻成什么语言可以在「场景助手 › 设置 › 即时翻译」里改（中文 / 日语 / 英语）。

**新增：AI 代理**
- 眼镜上长按左镜腿（在官方主界面上是单击左镜腿）说一句命令，确认后发到你自己的 GitHub 私有仓库（一条命令一个 Issue），
  由你的 AI 代理去处理；代理回复后眼镜上提醒，需要确认的事可以在眼镜上确认或取消。
- 「功能 → AI 代理」里填仓库和只给这个仓库 Issues 读写权限的令牌；「复制给代理的说明」可以直接交给代理。令牌只存在手机上。

**改进：提词、跟读**
- 提词器左上角显示进度百分比（按页数算，戒指翻页也准）。
- 退出阅读、导航后眼镜上不再一直显示「正在退出」。
- 跟读只往后找 3 行，随意发挥时不会乱跳；少于 5 个字的短行自动跳过。
- 只在提词、场景助手开着时才屏蔽通知（只开着阅读时照常提醒）。

**使用前**
- 场景助手要先下载离线转文字模型（约 166 MB），或者在设置里改用在线转文字；大模型用你自己的 Key（Groq、Gemini 有免费额度）。
- 即时翻译的语言包要能连上 Google 才能下载，下好之后不联网也能用。
- 导航要用你自己的 Google Maps Platform API Key；先强行停止 Nimo 官方 app，再用 NimoGo 连接眼镜。
- 从旧版本直接覆盖安装即可，设置不会丢。安装包只支持 64 位手机。这一版带了离线翻译引擎，安装包比上一版大一些。

**已知限制**
- 即时翻译能懂大意，专业名词可能翻得不准。对方可能说英语也可能说日语时，场景的语言选「自动」，转文字更准。
- 分辨「我 / 对方」靠音量：开头几句可能显示「分不清」；点手机上的那句话可以改，改过之后分得更准。
- 对方并不知道你在转写和翻译，请遵守当地法律、尊重对方；有的面试禁止使用辅助工具，请自己判断。
- 个人测试版本，只在 Android 16 上实测过。非官方项目，与 Nimo 厂商、Google 都没有关系。
