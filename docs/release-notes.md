## NimoGo v1.4.6

看板正显示着时，右镜腿双击打开语音菜单。念出功能名就马上启动，不用拿起手机。

**新增：语音菜单**
- 右单击仍是默认看板。看板开着时再右双击，眼镜上列出：阅读、导航、番茄钟、表盘、字幕、场景助手、代理、全天记忆、景点、聚会、跟读、小游戏。
- 说出名字就打开。说「小游戏」先列出游戏名，再说游戏名就启动。说「看板」回到看板。
- 蓝牙戒指：上键、下键移动选中的那一条，中间键启动。手机息屏时，音量加 / 减是上下，播放键是确认。
- 左单击返回（游戏名单上先回到功能名单），右单击关掉。右镜腿长按关掉菜单，回到看板。
- 菜单画在看板上，不打开提词器。听写用手机离线模型，没下载时菜单打得开但听不到（「全天记忆 › 设置 › 转文字」）。

**v1.4.5 的内容**
- 阅读和讲稿里的繁体字会整段换成简体再显示。

**使用前**
- 从旧版本直接覆盖安装即可，设置不会丢。安装包只支持 64 位手机。

**已知限制**
- 日语离线模型的输出没有标点，日语里夹的英文词会写成片假名；对方离得远、声音小时，准确度仍不如在线 Whisper。
- 「外语用在线」时，在线前的确认要用 SenseVoice，所以两个离线模型都要下载。
- 个人测试版本，只在 Android 16 上实测过。非官方项目，与 Nimo 厂商、Google、Meta 都没有关系。
