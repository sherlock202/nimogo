## NimoGo v1.1.0

提词功能大更新：语音跟读、蓝牙戒指翻页、演讲模式、粘贴文字新建讲稿；全天记忆和实时字幕可以在手机上离线转文字。

**语音跟读（新）**
- 阅读页打开「语音跟读」：眼镜麦克风听你念讲稿，手机上离线识别（SenseVoice，中日英都认，不联网），自动翻到念到的地方。
- 讲稿和识别结果按拼音对齐：繁体、简体、同音字、平翘舌、前后鼻音都对得上；从这一屏哪里开始念都能找到，跳过几句也能跟上，说讲稿以外的话会停在原地。
- 正在念的行放在倒数第二行（可改成最后一行或中间）。跟读时眼镜用文字显示（一次约 60 毫秒，比图片快得多），提词器顶部状态行显示听到的字。
- 第一次要下载识别模型（约 166 MB，建议连 Wi-Fi），和下面的「手机离线」转文字共用一个。
- 跟得不好时可以「导出跟读日志」。

**戒指翻页、演讲模式（新）**
- 阅读页里蓝牙戒指、方向键、翻页笔、媒体键都能翻：上下翻行，左右翻页（音量键按「阅读显示」里的设置）。
- 「演讲模式」：屏幕全黑、亮度最低但不锁屏，手机放进口袋戒指照常能用；手机屏幕被误碰不会翻，长按屏幕或按返回键退出。

**讲稿**
- 「粘贴文字新建讲稿」：剪贴板的文字自动填进去，存成 TXT 并打开（手机的「下载/NimoGo/讲稿」）；「编辑当前讲稿」可以修改。
- 修正：「打开书籍」选好文件后没反应。

**转文字**
- 全天记忆、实时字幕的转文字服务多了「手机离线」：不联网、不要 Key，海外没有网络延迟。
- 新增 Groq（Turbo）：海外服务器，有免费额度。

**其他**
- 新的 app 图标。
- 隐私说明更新（离线识别、讲稿文件），打开 app 时会再确认一次。

**使用前**
- 导航要用你自己的 Google Maps Platform API Key（设置步骤见 README）。
- 先强行停止 Nimo 官方 app，再用 NimoGo 连接眼镜。
- 从旧版本直接覆盖安装即可，设置不会丢。安装包现在只支持 64 位手机。

**已知限制**
- 语音跟读：日文段落只对得上汉字部分；识别和眼镜刷新加起来，大约在念完 0.5～1 秒后跟上。
- 演讲模式要屏幕亮着（全黑、最低亮度）：手机真正息屏后系统不会把按键交给任何 app。
- 个人测试版本，只在 Android 16 上实测过。非官方项目，与 Nimo 厂商、Google 都没有关系。
