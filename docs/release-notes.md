## NimoGo v1.5.1

修复镜腿按钮没反应，语音菜单改成用头来选。包括 1.5.0 的全部内容（锻炼、系统看板上的左镜腿、多列语音菜单）。

**镜腿按钮（番茄钟、锻炼）**
- 修：番茄钟和锻炼里，右单击开始 / 暂停、左单击重置或做完，有时像没反应。原因是同一次按下被算了两次（眼镜报了一次单击，App 又合成了一次，开始马上就被暂停），或者被当成长按退出，画面来不及变。现在同一下只算一次。
- 导航页上的单击不再被当成长按退出。真正的长按右镜腿仍然是退出。

**语音菜单：用抬头、低头选**
- 抬头往上，低头往下，在同一列里移动。头回到正位时不动，再抬头或低头才走下一格。
- 一列走到底，低头就到右边一列最上面；最右边一列最下面再低头，回到最左边一列最上面。最左边一列最上面抬头，到最右边一列最下面。
- 右单击启动选中的那一项（之前是关掉菜单）。左单击返回，右镜腿长按关掉，和以前一样。
- 菜单开着时，眼镜的「抬头显示」临时关掉，免得低头把屏幕关了；关掉菜单后恢复。
- 打开的功能沿用上次的设置：锻炼接着上次选中的运动组，阅读接着上次的那一页，番茄钟用上次的时长。

**说明**
- 戒指、音量键和手机上的方向键还是上下左右选，不受影响。
- 念出名字打开功能也还是一样。

**系统看板上的左镜腿**
- 单击：语音菜单。
- 双击：场景助手。
- 0.4 秒内连点三次：AI 代理。

**其他**
- 系统看板上右镜腿、左长按眼镜都不上报，这是眼镜固件的限制，App 收不到。

**使用前**
- 从旧版本直接覆盖安装即可，设置不会丢。安装包只支持 64 位手机。

**已知限制**
- 日语离线模型的输出没有标点，日语里夹的英文词会写成片假名；对方离得远、声音小时，准确度仍不如在线 Whisper。
- 「外语用在线」时，在线前的确认要用 SenseVoice，所以两个离线模型都要下载。
- 个人测试版本，只在 Android 16 上实测过。非官方项目，与 Nimo 厂商、Google、Meta 都没有关系。
