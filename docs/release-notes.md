## NimoGo v1.4.1

场景助手加了日语专用的离线模型：不联网也能比较准地认日语。

**新增：日语离线模型（ReazonSpeech）**
- 「场景助手 › 设置 › 转文字 › 日语离线模型」下载（约 160 MB，建议连 Wi-Fi）。ReazonSpeech 用约 3.5 万小时日语训练，只认日语，
  日常会话比默认的 SenseVoice 准得多。
- 下好后，日语场景走手机离线时（选了「手机离线」，或在线转文字失败时）自动用它；中文场景照样用 SenseVoice。
  可以在同一行选「不用它」切回 SenseVoice 对比，或删除模型。
- 从 Hugging Face 下载，连不上时换国内镜像，再不行从 GitHub 下完整的压缩包（约 700 MB，只解出要用的部分）。

**v1.4.0 的内容**
- 日语、英语场景默认用在线 Whisper 转文字；在线前先用手机离线确认是人在说话，Whisper 对着噪音编的「ご視聴ありがとうございました」之类会被丢掉。
- 即时翻译可以选用大模型（更通顺，要联网，出错时自动改用离线）。
- AI 代理的消息在眼镜上一直显示，按右镜腿才关；代理可以改发手机通知，由 NimoGo 替它写回 GitHub。

**使用前**
- 外语场景用在线转文字时，每句录音会发给你设的在线服务（比如 Groq）；不想发出去就选「手机离线」，日语配合日语离线模型使用。
- 从旧版本直接覆盖安装即可，设置不会丢。安装包只支持 64 位手机。

**已知限制**
- 日语离线模型的输出没有标点，日语里夹的英文词会写成片假名；对方离得远、声音小时，准确度仍不如在线 Whisper。
- 「外语用在线」时，在线前的确认要用 SenseVoice，所以两个离线模型都要下载。
- 个人测试版本，只在 Android 16 上实测过。非官方项目，与 Nimo 厂商、Google、Meta 都没有关系。
