## NimoGo v1.0.0

第一个公开版本：基于萤读（Yingdu）v1.0.3，加入海外可用的 Google 导航。

**新功能**
- 导航：在 Google Maps 里选好地点 →「共享」→ NimoGo，眼镜上显示转向箭头、距离、路名、下一步、剩余距离和预计到达时间。步行 / 驾车 / 骑行（不支持公共交通）。
- 也可以在「导航」页直接输入地名。
- 计费保护：每次开始前确认，本机按月计数，可设每月上限。
- 「全天记忆」可选 Google Gemini 转文字和总结，转文字多了日语。
- 闪退后下次打开会弹出闪退记录，方便反馈问题。

**使用前**
- 导航要用你自己的 Google Maps Platform API Key（启用 Navigation SDK，要绑结算账号；每月前 1000 个目的地免费）。设置步骤见 README「准备 Google 的 Key」。
- 先强行停止 Nimo 官方 app，再用 NimoGo 连接眼镜。

**已知限制**
- 个人测试版本，只在 Android 16 上实测过导航。
- 非官方项目，与 Nimo 厂商、Google 都没有关系。
