## NimoGo v1.1.4

修正：从 Google Maps 共享地点给 NimoGo 时，有时提示「没找到地点」。

**导航**
- 共享过来的只有地名时，和手动搜索一样先用你的 API Key 查（Google 地点搜索），店名、景点名也能找到；以前只用手机系统的地址查询，常常查不到。
- 短链接（maps.app.goo.gl）展开后看不出坐标时，会读 Google Maps 的网页，从里面取出地点坐标和名称。
- 展开后的地址里地名没编码（日文、空格）、或先跳到 Cookie 同意页时，也能正确解析。
- 还是找不到时，提示框会显示展开后的地址和出错原因；没填 API Key 时也会提醒。

**使用前**
- 导航要用你自己的 Google Maps Platform API Key（设置步骤见 README）。
- 先强行停止 Nimo 官方 app，再用 NimoGo 连接眼镜。
- 从旧版本直接覆盖安装即可，设置不会丢。安装包只支持 64 位手机。

**已知限制**
- 提词时长按右镜腿，眼镜会先显示「正在退出」再回到这一页，中间暗一下（约 1～2 秒），这是眼镜自己的处理，改不掉。
- 「抬头显示」关着时，看板收起后看到的是官方主界面，叫回时也会先露一下主界面。
- 语音跟读：讲稿里的人名、片假名外来语常常识别不准，跟不上时用戒指翻；大约在念完 0.5～1 秒后跟上。
- 个人测试版本，只在 Android 16 上实测过。非官方项目，与 Nimo 厂商、Google 都没有关系。
