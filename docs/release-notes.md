## NimoGo v1.2.0

新功能：场景助手。相亲、面试时，眼镜一直帮你听着，需要时在眼镜上给参考回答和可以问对方的问题，结束后在手机上复盘。

**场景助手**（「功能 → 场景助手」）
- 眼镜麦克风一直在听，在手机上转成文字，分出「我」和「对方」，我说的话标【我】。
- 右单击镜腿（戒指下键）：给 3 条参考回答，针对对方最近说的话；左单击（戒指上键）：给 3 个可以问对方的问题。同一个键再按一次收起。
  对方的话没认清时，复述确认一句（「您是问……吗？」）再按，会以你的复述为准。
- 建议长时分页：眼镜双击、戒指左右键、蓝牙耳机上一曲 / 下一曲、手机音量键都能翻。显示建议时最上面一行仍然显示听到的最新一句。
- 开始后手机进入黑屏模式、不弹通知；长按镜腿不会退出，只在手机上点「结束这一场」。
- 结束后复盘：相亲看对方的情况、性格和价值观、需要再确认的地方、你的表现；面试看职位的实际情况、是否适合你、需要追问的地方。
- 中文里夹英文专业名词：在场景里写上「专业名词」，大模型会按这些词理解；也可以改用在线转文字（Groq Whisper），中英混说更准。
- 大模型用你自己的 Key：Groq、Google Gemini 有免费额度，也支持 Claude、OpenAI、DeepSeek 和 OpenAI 兼容接口；现场和复盘可以用不同的型号。
- 普通版有「面试」场景；「相亲」等更多场景、自己添加场景需要私人定制密钥（「场景助手 › 设置 › 私人定制」，把设备码发给作者）。

**其他改进**
- 提词时长按右镜腿不退出，重新打开提词器更可靠（没开成会自动再开）。
- 阅读收起后（长按退出、关掉其他功能），按镜腿不会再把阅读叫出来，眼镜停在官方主界面；接着读在手机上点「恢复显示」。

**使用前**
- 隐私说明加上了场景助手，更新后会再请你确认一次。
- 场景助手要先下载离线转文字模型（约 166 MB），或者在设置里改用在线转文字。
- 导航要用你自己的 Google Maps Platform API Key；先强行停止 Nimo 官方 app，再用 NimoGo 连接眼镜。
- 从旧版本直接覆盖安装即可，设置不会丢。安装包只支持 64 位手机。

**已知限制**
- 分辨「我 / 对方」靠音量：开头几句可能显示「分不清」；点手机上的那句话可以改，改过之后分得更准。
- 只凭文字判断不了一个人是否说谎，复盘只会指出「值得再确认」的地方。对方并不知道在转写，请遵守当地法律、尊重对方。
- 手机息屏后，音量键、耳机键能否用取决于手机系统（日志里会记下收到了什么键）；戒指只在手机亮屏（黑屏模式）时能用。
- 个人测试版本，只在 Android 16 上实测过。非官方项目，与 Nimo 厂商、Google 都没有关系。
