## NimoGo v1.0.3

修正：在 NimoGo 里直接输入地名时，可能找到别的国家的同名地点，导航显示一万多公里、几千小时。

**改动**
- 直接输入地名时，先在所在城市找，再在国内找，最后才在全世界找。
- 找到好几个同名地点时，按远近列出来（名称、地址、距离），自己选。
- 开始导航前的确认画面会显示地址和直线距离；离得太远会用红字提醒「可能找错了地方」，取消不会算导航次数。

从 Google Maps 共享过来的地点和以前一样，不受影响。

**使用前**
- 导航要用你自己的 Google Maps Platform API Key（启用 Navigation SDK，要绑结算账号；每月前 1000 个目的地免费）。设置步骤见 README。
- 先强行停止 Nimo 官方 app，再用 NimoGo 连接眼镜。
- 从旧版本直接覆盖安装即可，设置不会丢。

**已知限制**
- 直接输入用的是手机系统的地址查询，车站、地区名比较准，店名可能找不到；这时请在 Google Maps 里找好再共享过来。
- 个人测试版本，只在 Android 16 上实测过导航。
- 非官方项目，与 Nimo 厂商、Google 都没有关系。
