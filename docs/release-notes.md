## NimoGo v1.4.3

眼镜上双击左镜腿，直接打开场景助手。

**新增：双击左镜腿打开场景助手**
- 用当前选好的场景。单击左镜腿（官方主界面）或长按左镜腿（看书、看板）仍然叫出 AI 代理。
- 单击翻页、看板翻屏不变。提词、跟读时左双击仍是上一章。场景助手开着时，左双击仍是翻页。
- 手机正开着 NimoGo 时，会和点「开始」一样进入黑屏模式。转文字还没准备好时，眼镜上会提示先下载离线模型，或设好在线转文字。

**v1.4.2 的内容**
- 手机通知里的繁体字先转成简体再显示到眼镜上。简体、英文和标点不变。

**使用前**
- 从旧版本直接覆盖安装即可，设置不会丢。安装包只支持 64 位手机。

**已知限制**
- 日语离线模型的输出没有标点，日语里夹的英文词会写成片假名；对方离得远、声音小时，准确度仍不如在线 Whisper。
- 「外语用在线」时，在线前的确认要用 SenseVoice，所以两个离线模型都要下载。
- 个人测试版本，只在 Android 16 上实测过。非官方项目，与 Nimo 厂商、Google、Meta 都没有关系。
